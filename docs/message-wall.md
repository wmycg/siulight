# 微光留言墙

- `/wall` 从导航下方铺满屏幕；指针/触摸拖动，方向键移动视口，点击纸条阅读全文。
- 纸条按内容和确定性随机值产生不同宽高、旋转和错位。数量足够时循环展示真实纸条形成无边界墙；重复实例始终对应同一条留言，不制造新数据。少于 8 张时不循环复制。
- 起一阵风：本地重排并轻轻抬起纸条；不修改数据库。系统减少动态效果设置会关闭重排过渡。
- 娃娃机：方向按钮、方向键或滑杆瞄准，抓取/空格开始；对准范围内的真实纸条会被提起并展开，未对准会抓空。免费游玩，无支付。按 F 全屏，Esc 退出。
- 登录成员以账户名称发布；游客可留可选署名，不填则使用“路过的同好”。每条最多 280 字，五种纸色。选色首项是默认选中的“随机颜色”；书写预览固定为黄色，发布时保存自动配色选项，展示时按纸条 ID 分配稳定的随机颜色，墙面、弹窗和娃娃机一致。也可指定固定颜色。
- 纸条公开可读。游客所有权由 HttpOnly 同源 Cookie 标识，数据库只保存随机令牌哈希；清除浏览器 Cookie 后无法再以原游客身份收回。成员可收回本人纸条，管理员可移除任何纸条。阅读弹窗提供收回入口。
- 发布接口按 IP 限制每 15 分钟 20 次，并沿用全站跨源写入校验。正文按纯文本呈现。

## 数据库和运行

使用 pnpm。已有项目更新后执行 `pnpm db:migrate`，生产 `pnpm start` 已自动执行迁移。新环境执行 `pnpm run setup`。增量迁移 `20260913153240_add_message_wall` 创建 `wall_notes`，保留现有数据。

开发 `pnpm db:seed` 会添加 24 张明确标记“示例纸条”的演示留言。生产不会自动种入演示内容。

`pnpm test` 验证抓取规则，`pnpm test:integration` 验证真实 MySQL 的游客/成员身份、公开读取、内容校验、分页和删除权限，`pnpm test:migrations` 验证首次安装、增量部署、重复部署及失败阻断启动。
