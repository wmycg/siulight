# 微光漫摄 · 重写架构

## 技术与边界

React + TypeScript + Vite 构建浏览器端，Express + TypeScript 提供同源 JSON API，mysql2 连接 MySQL 8.4。pnpm 是唯一包管理器。UI 使用 shadcn/ui 的源码式组织方式（Radix UI、Tailwind CSS、CVA），基础组件保存在 `src/components/ui` 并根据品牌做了外观定制。

```text
src/
  components/        跨业务组件；ui/ 为 shadcn/ui 基础组件
  features/          auth、events、milestones、admin 的业务组件
  pages/             路由页面与内容编排
  lib/               API 客户端、查询缓存、格式化工具
server/
  routes/            请求校验、权限和 HTTP 响应
  services/          里程碑聚合与事务、密码散列、审计
  middleware/        会话识别和角色校验
  db/                MySQL 连接、版本化建表、可重复演示种子
shared/              浏览器与服务端共享的领域类型、Zod 校验、社团内容
public/images/       本地插画、原站二维码海报
storage/uploads/     上传图片（运行时目录，不提交 Git）
tests/               领域测试与真实 MySQL API 集成测试
```

开发时 Express 同时托管 Vite 中间件与 API，统一 `http://localhost:3000`。生产时 Express 托管 Vite 构建后的静态文件，Node 服务端独立构建到 `dist/server.js`。React Router 处理前端路由，页面模块按路由懒加载。TanStack Query 管理服务器数据、刷新和加载/错误状态；页面不以 localStorage 冒充数据库。

## 核心模型

- `users`：成员、管理员、超级管理员；公开信息只含昵称、头像色、简介。邮箱仅本人或超级管理员可见。
- `sessions`：随机会话令牌仅在浏览器 HttpOnly Cookie 中保存；数据库保存 SHA-256 摘要，14 天过期。
- `milestones`：标题、正文、实际发生日期、个人/社团归属、分类、可选图片、作者。
- `milestone_participants`：多人共同署名关系；作者自动参与，另外最多 12 位。共同记录出现在所有参与者的公开纪念册。
- `likes`：成员与纪念的联合主键，重复点击不会重复计数。
- `events` / `event_attendees`：公开活动及报名关系。报名时锁定活动行，容量校验与写入在同一事务内。
- `applications`：入社表单与状态（待联系、已联系、已入社）；学号唯一，个人信息仅管理员可见。
- `audit_logs`：管理行为日志；不记录密码和申请表完整内容。
- `_prisma_migrations`：Prisma Migrate 的迁移历史与执行状态。模型位于 `prisma/schema.prisma`，后续改表新增迁移，部署自动应用。原 `schema_migrations` 和手写版本 1 迁移器已移除。

## 里程碑的展示规则

公开纪念册按年份倒序，默认展示所有人。提供社团足迹、个人时刻、我的纪念、年份与关键词筛选，每页 12 条。每个年份在桌面显示双列纪念，轻微错位形成相册节奏；DOM 顺序仍保持时间顺序。手机改为单列，日期与作者信息不省略。

有图记录像相纸，无图记录采用有留白的便笺。单条记录限制舒适阅读宽度，不拉伸成空旷双栏。共同记录显示至多 4 个头像与溢出人数；点开详情可查看全部署名者。作者可修改或删除自己的记录，管理员可删除违规记录。社团官方记录仅管理角色可发布。发布前提示先征得伙伴同意；当前共同署名不是邀请审批系统。

## 访问控制与输入

所有写入在服务端经 Zod 再次校验。SQL 使用参数绑定。通过 Origin 和 Fetch Metadata 拒绝跨站写入，Cookie 为 SameSite=Lax；正式环境使用 Secure Cookie，需 HTTPS。注册、登录、表单与上传均有限流。

密码使用随机 salt + scrypt，比较使用 timingSafeEqual；变更密码撤销其他会话，权限修改撤销目标账号会话。超级管理员不能删除自己，也不能通过普通角色接口降级其他超级管理员。已有纪念的账号不能直接删除，以免破坏作者归属。

图片最大 8 MB，通过 sharp 解码、限制像素数量、转为 WebP，移除原始元数据，并使用随机文件名。仅允许本站 `/images/` 或 `/uploads/` 路径进入内容字段。生产 CSP 禁止外部脚本与外部图片。正文按纯文本渲染，不执行 HTML。

## 正式环境准备

生产启动会校验 `DATABASE_URL`、端口和 `APP_ORIGIN`/`APP_ORIGINS`；域名必须填写实际来源且不能带路径、查询参数或片段。

演示账号和演示活动/纪念只用于本地测试。生产部署前应移除演示记录、设置真实内容和管理员密码；演示种子在 NODE_ENV=production 时主动拒绝执行。邮箱目前作为登录标识，未接入邮件验证或自助找回密码。上传文件应持久化并备份；多实例部署需改为共享对象存储。服务反向代理时需结合实际代理配置限流 IP，不盲目信任外部代理头。生产仅支持经过 HTTPS 反向代理的访问，APP_ORIGIN 必须填写实际域名。

留言墙的公开数据与身份权限由 `server/routes/wall.ts` 管理，表结构在 Prisma 的 `WallNote` 模型及增量迁移中维护。客户端按游标取数据，`src/features/wall` 分离纸条展示、拖拽视口、发布/阅读弹窗与娃娃机状态机。`/departments` 保留为兼容入口，重定向到 `/about` 对应锚点。
